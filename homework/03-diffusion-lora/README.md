# ДЗ 8 · Stable Diffusion: генерація, гіперпараметри й DreamBooth-LoRA

До занять 7–8. ≈ 3 години (з них 10–20 хв модель вчиться сама), 15 балів.

Ноутбук: [`03-diffusion-lora.ipynb`](03-diffusion-lora.ipynb). Працює в Google Colab на безкоштовній T4, локальне
середовище `cv-advanced` тут не знадобиться: diffusers і peft конфліктують з рештою пакетів курсу. У Colab —
File → Upload notebook, далі Runtime → Change runtime type → T4 GPU. Комірка встановлення оновлює diffusers,
transformers, accelerate і peft та прибирає передвстановлений torchao, з яким новий peft падає. Якщо після неї
імпорт не проходить, зробіть Runtime → Restart session і запустіть комірки ще раз.

Ваги SD 1.5 (≈ 4 ГБ) ноутбук сам тягне з HF-дзеркала `stable-diffusion-v1-5/stable-diffusion-v1-5`, скрипт навчання —
з репозиторію diffusers під встановлену версію.

Фото підготуйте заздалегідь: 8–15 знімків одного об'єкта (улюбленець, іграшка, чашка, кросівки) з різних боків і на
різному фоні або 10–20 картинок в одному стилі. Як знімати й три способи залити їх у Colab, описано в розділі 3.1
ноутбука. Без своїх фото можна взяти `DATA_SOURCE = "demo"` (5 фото собаки з HF), але тоді мінус бал за власні дані.

| Частина | Що робите | Час |
|---|---|---|
| 1 · базова генерація | `generate` з фіксованим seed і чесним заміром часу на GPU → 3+ промпти | 10 хв |
| 2 · параметри | `run_sweep` → seed, guidance scale, кроки → `set_scheduler` і 7 семплерів × 10 / 20 / 30 кроків → negative prompt → цикл CFG власноруч, який має дати ту саму картинку, що й `pipe(...)` | 40–60 хв |
| 3 · DreamBooth-LoRA | обрізання фото → промпт `sks <клас>` → 500 кроків офіційним `train_dreambooth_lora.py` → 6+ промптів у нових сценах, до / після, сила LoRA від 0 до 1,25, чекпоінти 250 і 500 | 60–90 хв |
| 4 · бонус, без балів | img2img і `strength`, CLIP-I / CLIP-T залежно від сили LoRA | 20–30 хв |
| 5 · висновки | 3–5 речень, зокрема чим LoRA відрізняється від навчання з нуля | 15 хв |
