How it works

      
    
        
  1. Features. SIFT finds keypoints in every image (scale-space extrema) and describes each with a 128-D gradient histogram.
    2. 
        
  2. Matching. Descriptors are matched between image pairs (all pairs, or the next N for a video-like sequence). A RANSAC fit of the fundamental / essential matrix or homography keeps only geometrically consistent inlier matches.
    3. 
        
  3. Incremental mapping. Start from a well-connected pair (relative pose from E, triangulate), then repeatedly register the next image by PnP against existing 3D points, triangulate new points and run bundle adjustment:
          
    min Σi,j ρ( ‖ π(Kc, Ri Xj + ti) − xij ‖² )
    
          The residual for each point is its reprojection error, and the number of images that see it is its track length.
    4. 
        
  4. Global mapping (GLOMAP) instead averages all relative rotations, then solves for all positions at once, and runs bundle adjustment at the end.
