How it works

  1. Bake. At each of the 128³ voxel centres the MLP is queried once: F(x) → σ, feat. Colour depends on view direction d, so it is evaluated for 48 directions and fitted with spherical harmonics, giving c(x,d) ≈ Σ klm(x) Ylm(d).
  2. March. For every pixel a ray r(t) = o + t·d is clipped to the grid box and sampled every δ. σ and the SH coefficients come from trilinear texture lookups instead of MLP calls.
  3. Composite.
    αi = 1 − exp(−σi δ)
    Ti = ∏j<i (1 − αj)
    C = Σi Ti αi ci + TN · Cbg
    These are the same equations NeRF uses in training (volume_render_radiance_field).
