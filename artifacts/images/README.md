# Зображення для демо

Фото й кадри, які вантажимо в панелі занять. Комітяться в git разом із кодом,
тож кладемо сюди лише те, що потрібне демо, і стискаємо до розумного розміру.

## Калібрування (заняття 2, demo1)

```
calibration/
    chessboard/   фото шахівниці (*.jpg, *.png, …)
    charuco/      фото ChArUco
```

- Одна камера, одна роздільність, незмінні фокус і зум (автофокус краще вимкнути).
  Кадри іншої роздільності, наприклад зняті вертикально, ноутбук відкине сам.
- 20–40 знімків на мішень, під різними нахилами й у різних місцях кадру, зокрема біля
  країв. Кілька суто фронтальних кадрів і кілька лише в центрі теж варто зняти: на них
  ноутбук показує, чим вони гірші.
- Дошки курсу (A3, друк 100 %): шахівниця `checkerboard_A3_9×6_34mm` — 10×7 клітинок,
  9×6 внутрішніх кутів, крок 34 мм; ChArUco `charuco_A3_9x6_40mm` — 9×6 клітинок по 40 мм,
  маркер 30 мм, `DICT_5X5_250`. Перед зйомкою звір лінійку контролю масштабу на аркуші.
- Параметри надрукованих дошок (кути шахівниці, клітинки, маркер і словник ChArUco)
  задаються в першій клітинці коду `lesson_02_demo1_calibration.ipynb`.
