# Зображення для демо

Фото й кадри, які вантажимо в панелі занять. Комітяться в git разом із кодом,
тож кладемо сюди лише те, що потрібне демо, і стискаємо до розумного розміру.

## Калібрування (заняття 2)

```
calibration/
```

звідки взяти готові набори і чого не змішувати — у
[`calibration/README.md`](calibration/README.md).
