# Артефакти

Важкі бінарники, спільні для занять: ваги моделей, зображення й датасети для демо.

```
artifacts/
  models/   ваги (*.pt, *.onnx, *.engine, ...)
  images/   фото та кадри для демонстрацій
  kitti/    KITTI odometry для заняття 3
  visdrone/ VisDrone-VID для заняття 5
```

Ваги й датасети в git **не потрапляють** — лише структура тек і ці README.
Виняток — `images/`: фото для демо невеликі, тож їх комітимо. Тримати все тут, а не
в теці конкретного заняття, бо одні й ті самі ваги потрібні кільком заняттям, і
дублювати 40 МБ по дев'ятнадцяти теках немає сенсу.

## Як на це посилатися з коду

Шляхи рахуються від кореня репозиторію, тому не залежать від того, звідки
запущено ноутбук. У занятті 1 їх дає `panels.py` (ноутбук заняття імпортує його
зі своєї теки):

```python
from panels import MODELS_DIR, IMAGES_DIR, model_path

MODEL = YOLO(model_path("yolo11n.pt"))
```

`model_path()` завжди віддає шлях в `artifacts/models/`. Якщо файлу там немає,
ultralytics завантажить стандартні ваги з інтернету саме туди — тож на занятті без
інтернету їх треба покласти заздалегідь.
